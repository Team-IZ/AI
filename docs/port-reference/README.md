# port-reference — 이식 대조용 원본 스냅샷 (동결)

이 디렉터리의 `app.js` / `p02-runner.js` / `p03-runner.js`는 포팅 **이전** 원본 Pipeline Lab
소스의 2026-07-28 시점 스냅샷입니다. (2026-08-03에 `reference/` → `docs/port-reference/`로
경로만 옮겼고, 파일 내용은 바이트 단위로 그대로입니다.)

두 가지 이유로 보존합니다:

- **(a) 이식 검증 방법론의 대조군.** `Readme.md`의 "이식 방법론"/"검증" 절은 이 포트의 검증
  방식을 *`shared/p02-engine.js`·`shared/p03-engine.js`를 이 파일들과 diff한다*로 정의합니다.
  이 프로젝트의 원칙은 "요약을 보고 재작성"이 아니라 **원본을 통째로 복사한 뒤 DOM 접점만
  빼기(copy-then-subtract)**이고, 그 주장은 원본이 남아 있어야만 재현·반증할 수 있습니다.
- **(b) `shared/code-locate.js`의 `MIN_SYMBOL_LEN = 9` 근거 코퍼스.** D-ground1m(2026-07-31)이
  임계값을 손으로 고른 8에서 실측값 9로 대체할 때 쓴 코퍼스(62개 파일 / 비어있지 않은 줄
  14,855개)에 이 디렉터리가 포함돼 있습니다. 파일을 지우거나 내용을 고치면 그 측정을 다시
  돌릴 수 없습니다.

**이 파일들은 동결된 참조 자료이며 유지보수 대상 코드가 아닙니다.** 버그를 발견하더라도 여기서
고치지 마세요 — 실행되는 코드는 `shared/`에 있습니다. 내용을 수정하면 위 (a)·(b) 두 근거가
동시에 재현 불가능해집니다.
